【解】【答案要点】（1）算法的基本设计思想：建立图G 各顶点的入度表degree[]。选择入
度为0 的顶点v，将v 的所有邻接点的入度减1，重复执行这个过程。若每次选中的入度为
0 的顶点有且仅有一个，且共进行了G.numVertices 次，则意味着存在唯一的拓扑序列，返
回1，否则不存在拓扑序列，或存在多个拓扑序列，返回0。（2）用C 语言描述的算法：
207

int uniquely(MGraph G)
// 判定有向图是否存在唯一的拓扑序列
{
int *degree, i, j, count=0, in0=-1, prev_in0;
degree=(int*)malloc(G.numVertices*sizeof(int));
for(j=0; j<G.numVertices; j++) {
// 计算各顶点的入度
degree[j]=0;
for(i=0; i<G.numVertices; i++)
degree[j]+=G.Edge[i][j];
if(degree[j]==0) {
if(in0==-1) in0=j;
// 入度为0 的顶点
else in0=-2;
// 有多个入度为0 的顶点
}
}
while(in0>=0) {
count++;
prev_in0=in0;
in0=-1;
for(j=0; j<G.numVertices; j++)
if(G.Edge[prev_in0][j]>0) {
if(--degree[j]==0) {
// 邻接点入度值减1
if(in0==-1) in0=j;
// 入度为0 的顶点
else in0=-2;
// 有多个入度为0 的顶点
}
}
}
free(degree);
if(count==G.numVertices) return 1;
else return 0;
}
if(in0==-1) in0=j;
// 入度为0 的顶点
else in0=-2;
// 有多个入度为0 的顶点
}
}
}
free(degree);
if(count==G.numVertices) return 1;
else return 0;
}

【解】【答案要点】（1）算法的基本设计思想：从后向前扫描一趟数组A，对每个A[i]（0 ≤
i ≤n −1），分别找到从A[n −1] 到A[i] 中的最大值Max 和最小值Min，然后分以下情况
处理：①若A[i] ≥0，则A[i] 与Max 相乘；②若A[i] < 0，则A[i] 与Min 相乘。相乘的
结果保存在res[i] 中。
41．（续）（2）算法实现：
215

void calMulMax(int A[], int res[], int n)
{
int i, Max, Min;
Max=Min=A[n-1];
for(i=n-1; i>=0; i--) {
// 从后向前扫描数组A
if(A[i]>Max) Max=A[i];
else if(A[i]<Min) Min=A[i];
if(A[i]>=0) res[i]=A[i]*Max;
// 根据A[i] 的正负性分别处理
else res[i]=A[i]*Min;
}
}
（3）算法的时间复杂度为O(n)，空间复杂度为O(1)。

单项选择题
第1 题
【答案】A
【考点】顺序表
【解】表头插入须把原有n 个元素后移一格，表头删除须把其余n−1 个元素前移一格。n≥3，
两种操作均移动多个元素。表尾插入或删除只改表尾和表长。
第2 题
【答案】D
【考点】双向链表
【解】遍历沿p1 进行，因此可以边走边改p2。对每个结点先判断p1 是否为空，若非空取
后继的p1，否则将p2 置空。每轮都推进cu，避免越界或死循环。
A 在尾结点会访问空指针，B 以旧的前驱指针为遍历条件，首结点前驱为空时就会停止；C
遇到没有后继的尾结点时不再推进。D 则在每轮末尾统一沿p1 前进。
第3 题
【答案】C
【考点】二叉树遍历
【解】层序首结点a 是根；中序将其分成左子树b,e,d,f,c 和右子树g。左子树根为b，向右
接c；c 的左子树根为d，d 的左右孩子是e、f。按左、右、根输出e,f,d,c,b,g,a。
第4 题
【答案】B
【考点】森林与二叉树转换
【解】五棵树的根会形成一条右兄弟链。最后一棵树至少有两个结点，所以第5 层的根下至
少再有一层。把每棵树构造成根带若干叶的树，并把含两个结点的树放在末尾，可将最深路
径限制为6 层。
第5 题
【答案】D
【考点】哈夫曼树
【解】依次合并最小权值，得到1+2=3、3+4=7、5+7=12、8+10=18、12+12=24，最后18+
24=42。e、f 共同挂在权18 的结点下，g 挂在权24 的结点下，三者深度相同。

第8 题
【答案】D
【考点】AVL 树
【解】高度按层数计。根的两个子树高度至多相差1，最大差取高度3 的满子树与高度2 的

第41 题
【考点】二叉搜索树查找
【解】沿搜索k 的路径记录最接近k 的较小键和较大键。若当前键小于k，它的左子树更小，
可以排除；当前键大于k 时同理排除右子树。等于k 时差为0；走到空指针时，在两个候选
中比较差值，若相同则都输出。
#include <stdio.h>
void searchX(BTree root, int k) {
BTree lo = NULL, hi = NULL;
for (BTree p = root; p != NULL; ) {
if (p->data == k) {
printf("0 %d\n", k);
return;
}
if (p->data < k) {
lo = p;
p = p->right;
} else {
hi = p;
p = p->left;
}
}
if (lo == NULL && hi == NULL) return;

/* 先扩宽再作差，避免int 边界值相减溢出。*/
long long left = lo ? (long long)k - lo->data : 0;
long long right = hi ? (long long)hi->data - k : 0;
if (lo && (!hi || left <= right))
printf("%lld %d\n", left, lo->data);
if (hi && (!lo || right <= left))
printf("%lld %d\n", right, hi->data);
}
