# 备考台 · 2027 考研刷题台

双用户考研刷题应用（本地 SQLite；线上账号登录 + 游客 1v1）：**政治 + 英语二 + 数学二 + 408**。按 2027 考研大纲动态组卷，做题后由 DeepSeek 批改；支持跳过、下一题、做同类题、持续追问，以及带全局学习档案的 AI 答疑。

## 功能

- **四科刷题**：政治、英语二、数学二、408，按 2027 大纲的题型、分值与章节组织。
- **动态组卷**：选择科目 → 章节 → 快速一组 / 整卷模考，模型现编题目；不会预先剧透答案。
- **AI 批改**：客观题本地判分；数学解答、英语翻译/写作、政治分析、408 综合题由模型按步骤给分，输出得分、维度、失分点、参考步骤和下一步建议。
- **手写图片**：主观题可拍照/上传手写解答，模型结合图片批改。
- **手机扫码上传**：电脑端生成一次性二维码，手机扫码拍照或选图，图片自动回填到当前题；二维码 10 分钟有效。
- **做同类题**：针对刚做过的题，生成同章节、同题型、同难度的新题并追加到当前试卷。
- **追问模式**：围绕一道题持续对话，问“为什么”“还有别的方法吗”“这个考点还会怎么考”。
- **AI 答疑**：独立答疑页，老师先读学习档案，再按“小步引导 → 检查理解 → 出题巩固”的节奏推进；回复默认短、一次只问一个点，支持快速判断卡和填空卡，答完自动继续。
- **资料检索**：每次答疑自动检索本地题库、2027 大纲；需要最新或外部信息时使用 DeepSeek 的 `deepseek_web_search` 联网搜索，并附参考来源。
- **全局学习档案**：把试卷作答、随机刷题、1v1、答疑出题合并成 `LearnerProfile`，每次答疑自动注入；同时写入 `data/learner/<userId>.json` 方便检查。
- **学习路线**：老师在答疑中维护分级的待办清单（待学/进行中/完成），用户可在右侧查看并勾选完成，下一轮自动带入。
- **双用户**：`hifive` 与 `study` 两个账号，练习、错题、随机刷题、比赛记录互相隔离。
- **随机刷题**：打开就是一题，不选科目/章节，点选项即判，随时退出；题库覆盖数学二、英语二短题、政治、408。作答后可原地「追问」，对话按题目保存。
- **1v1 竞赛**：匹配在线考生，10 道混合题，按难度限时，实时显示对手进度；支持游客一次性会话。
- **暗黑模式**：亮色/暗黑一键切换，统一 tokens 适配。
- **练习记录 / 错题本**：自动记录每次作答、跳过、得分与批改反馈；错题可按科目回看并重做。
- **真题库**：2006—2026 年（英语二 2010 起、408 2009 起）真题已整理为 Markdown，内置 KaTeX 渲染，供阅读和 AI 检索。
- **2027 大纲**：四科大纲原文与章节树，生成题目时自动带入结构和高频考点。

## 快速开始

```bash
npm install
cp .env.example .env.local
# 编辑 .env.local，填入 DEEPSEEK_API_KEY
npm run dev
# 打开 http://localhost:3000
```

当前仓库的 `.env.local` 已放入一个临时 key（仅本地开发用，已被 `.gitignore` 忽略）。**请尽快换成你自己的 key，并不要提交到任何仓库。**

### 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 无 | 必填，服务端调用 |
| `DEEPSEEK_MODEL` | `deepseek-flash` | 模型名 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | API 地址 |
| `DEEPSEEK_EFFORT` | `low` | 推理强度，可选 `low/high/max`；越高越慢 |
| `APP_DB_PATH` | `data/app.db` | SQLite 路径（可选） |

### 生产构建

```bash
npm run build
npm run start
```

本地运行即可；如果要部署到云端，需要把 SQLite 与 `data/uploads` 换成对象存储/数据库，并加访问控制。当前版本为双账号、无应用内角色权限；线上登录由应用处理，游客只能进入 1v1。

## 组卷与批改是怎么工作的

1. **组卷**：按所选章节从 `data/bank/*.json` 抽 3 道真题作为风格参考（不直接照抄），把 2027 大纲的题型结构、分值、章节要求、学生近期薄弱点一起送入模型。
2. **分组并行**：把一份卷拆成选择、填空、解答等小任务并行生成，缩短等待时间；英语阅读/写作、408 选择/综合会再按科目拆分。
3. **答案校验**：生成结果统一清洗题型、章节、选项、分值；数学解答题按 70 分、408 综合按 70 分等结构归一化。
4. **批改**：客观题本地比对答案；主观题把题干、标准答案、解析、评分要点、学生作答（和手写图片）一起交给模型，要求返回 JSON 分数与分项反馈。
5. **追问**：把题目、答案、解析、最近一次作答与批改结果作为上下文，流式返回辅导对话；随机刷题使用同一套追问面板，消息按用户 + 题目保存。
6. **答疑**：`lib/learner.ts` 把试卷、随机刷题、1v1、答疑出题聚合成用户学习档案；`/api/tutor/chat` 注入压缩后的档案，默认限制输出长度；`/api/tutor/quiz` 由系统出题并渲染成对话内卡片，答案在提交后才返回。

## 已知限制

- 模型生成题可能出错（答案、计算、表述），请以教材/真题为准；重要结论建议对照真题库。
- 真题材料来自公开整理，存在 OCR/回忆版误差；408 部分题图未随文本保存。
- 英语二参考译文与写作范文为 AI 生成，不是官方答案。
- 当前为双账号、应用内登录；游客只能进入 1v1。请勿在去掉登录保护后直接公开 API。
- 生成整卷（尤其英语二 48 题）耗时较长，建议先用快速一组。
- 答疑老师的判断仍可能出错；学习档案是自动汇总，不代表已经掌握某个知识点，最终以真题/教材为准。
